# 2. Config Folder Specification

The `config/` directory is the **single source of truth for all runtime settings and file paths**. It reads from `user-config.json` and the process environment, merges them into a typed singleton, and exposes that object to every other folder in the project. Static file path constants live in `config/paths.ts`.

> [!IMPORTANT]
> **Folder Behavior & Philosophy:**
> 1. **Singleton & Read-Only at Runtime**: The `config` object is built once at startup and treated as immutable by all consumers. The only exception is `reloadScreeningThresholds()`, which performs a targeted hot-reload of screening fields (called by the lessons engine after threshold evolution) — no other partial mutations are allowed.
> 2. **No Business Logic**: This folder must not contain any trading decisions, strategy evaluation, or state management. It only resolves, coerces, and validates parameters from the environment and user config file.
> 3. **Environment Priority**: Sensitive values (wallet keys, RPC URLs, LLM API keys) are loaded from environment variables first, and `user-config.json` values are applied only if the corresponding `process.env` entry is absent. This ensures that encrypted `.env` values always take precedence.

## Architecture Design: Config Lifecycle

The configuration builds in three stages at import time:

```
  .env (encrypted via utils/secure-env.ts)
       │
       ▼  [loadEnv() decrypts sensitive keys into process.env]
  process.env
       │
       ├── WALLET_PRIVATE_KEY, RPC_URL, LLM_API_KEY, etc.
       │
  user-config.json   ──►  Raw user overrides (str / num / bool helpers)
       │
       ▼
  ┌──────────────────────────────┐
  │     config/index.ts          │
  │  Merges env + user config    │
  │  into typed Config singleton │
  └──────────────────────────────┘
       │
       ▼
  export const config: Config   ←── consumed by ALL other folders

  ┌──────────────────────────────┐
  │     config/paths.ts          │
  │  Static file path constants  │  ← consumed by core/, llm/, cli.ts, index.ts
  └──────────────────────────────┘
```

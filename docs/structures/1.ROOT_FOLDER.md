# 1. Root Folder Specification

The root directory of the Meridian project acts as the primary orchestration center, command entry point, and build configuration workspace. Under the target architecture, only entry points, runner files, and root-level package configs permanently reside here.

---

## Permanent Files

### 1. [`index.ts`](file:///Users/ichadhr/Develop/node/meridian/index.ts)
* **Role**: Primary entry point for the autonomous agent.
* **Current Operations**:
  - Sets up the interactive REPL shell.
  - Controls cron scheduling for both `runScreeningCycle()` and `runManagementCycle()`.
  - Runs the Telegram bot polling server, processes incoming Telegram chat commands, and formats alerts.
  - Implements concurrency guards (`_screeningLastTriggered`, `_managementBusy`) to prevent race conditions.
* **Restructuring Goal (Shrinking index.ts)**:
  `index.ts` is currently a monolithic file of ~2,000 lines. During the upcoming restructuring, its functionality will be extracted into target folders as follows:

  #### A. Extraction to `core/` (Pure Logic & Orchestration)
  * **To `core/close-rules.ts`**:
    - `getDeterministicCloseRule()` (Stop-loss, take-profit, low yield, and OOR exit rules)
    - `schedulePeakConfirmation()` & `scheduleTrailingDropConfirmation()` (Trailing rechecks)
    - `shouldUsePnlRecheck()`
  * **To `core/vp/digest.ts` & `core/vp/report.ts`**:
    - `computeBinsBelow()` (Linear bins below scaling calculation)
    - `getLoneCandidateSkipReason()`
    - `setLatestCandidates()`, `getLatestCandidatesMeta()`, and `describeLatestCandidates()`
  * **To `core/live/manage.ts`**:
    - `runManagementCycle()` (Live position monitoring, close rule evaluation, OOR handling)
  * **Stays in `index.ts` (Orchestration entry points)**:
    - `runScreeningCycle()`
    - `startCronJobs()` & `stopCronJobs()` (Cron runner controls)
    - `launchCron()` & `runBusy()` (Cycle wrappers)
    - `shutdown()`

  #### B. Extraction to `interfaces/telegram/` (User Communications)
  * **To `interfaces/telegram/index.ts`**:
    - `telegramHandler()` (Inbound Telegram message routing & command execution)
    - `closeTelegramPosition()` & `deployLatestCandidate()`
    - `drainTelegramQueue()`
    - `formatHelpText()`
    - `fmtPct()`, `formatWalletStatus()`, and `formatCandidates()` (Formatting outputs)
    - `runBriefing()` & `maybeRunMissedBriefing()` (Briefing triggers)
    - Settings menu keyboard and callback handlers: `renderSettingsMenu()`, `showSettingsMenu()`, `applySettingsMenuCallback()`, `normalizeMenuValue()`, `settingButton()`, `toggleButton()`, `stepButtons()`, `fmtSettingValue()`, `parseConfigValue()`, `settingValue()`, and `formatConfigSnapshot()`

  #### C. Extraction to `llm/` (Agent Loop Context)
  * **To `llm/prompt.ts`**:
    - `buildPrompt()` & `refreshPrompt()` (Agent system prompt orchestration)
    - `appendHistory()` (Conversational history helper)
    - `stripThink()` & `sanitizeUntrustedPromptText()` (LLM output parsers)

### 2. [`cli.ts`](file:///Users/ichadhr/Develop/node/meridian/cli.ts)
* **Role**: Command-Line Interface (CLI) runner.
* **Operations**:
  - Exposes 28+ commands and subcommands (e.g. `positions`, `pnl`, `deploy`, `screen`, `manage`, `lessons`, `blacklist`).
  - Allows direct execution of individual agent functions and tools with formatted JSON outputs.
  - Supports script overrides and development debugging flags (e.g. `--dry-run`, `--silent`).

### 3. [`setup.ts`](file:///Users/ichadhr/Develop/node/meridian/setup.ts)
* **Role**: Setup wizard.
* **Operations**:
  - Provides a step-by-step interactive CLI questionnaire to configure risk profiles, API credentials, and wallets.
  - Builds the initial `.env` and `user-config.json` files based on predefined templates and safety limits.

### 4. Build & Process Configs
* **[`package.json`](file:///Users/ichadhr/Develop/node/meridian/package.json)**:
  Defines project metadata, dependencies (e.g. `@meteora-ag/dlmm`, `@solana/web3.js`), and run scripts.
* **[`tsconfig.json`](file:///Users/ichadhr/Develop/node/meridian/tsconfig.json)**:
  Specifies the TypeScript compiler options. Configures compilation output to the `dist/` directory.
* **[`ecosystem.config.cjs`](file:///Users/ichadhr/Develop/node/meridian/ecosystem.config.cjs)**:
  PM2 process manager configuration, optimized for keeping the Telegram bot and polling loop active continuously on a VPS.
